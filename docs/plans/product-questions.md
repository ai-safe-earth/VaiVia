# Product questions

Moved from `product-status.md` (last updated 2026-08-17) on 2026-10-08.

## What VaiVia is

A voice- and text-driven route planner for hikers, trail runners and mountain
bikers: you describe the outing in plain language and it draws the route. An
end-user product; the graph and the API are internal infrastructure, not the
thing being sold.

Strategy: conversation replaces the filter panel. Compound asks (a trail, a
hut, a station) that flat trail apps like Komoot, Wikiloc and AllTrails cannot
answer, and natural language is the only interface that makes them askable.

## Decided

- 2026-08-16 — end-user product, not an API product.
- 2026-08-17 — the brand name is VaiVia (supersedes "GetOutdoor").
- Brand voice: engineering honesty carries into the brand; no safety
  guarantees about routes or trail conditions.
