# Phase 11 — One UI (layout ratified 2026-08-28)

> **Superseded in part by U7 (owner decision 2026-09-29):** there is no map layer any more. A card opens in place, in the transcript, with its own map; the `.map-layer`, `.route-panel`, `#map`, `view`, `picked`, `onPick` and the header Map button below are history, kept for the record. The rest of this phase (the shell, the composer, the viewport, Saved routes over the transcript) stands.

U0 `fix/lime-everywhere` lands first. Owner-locked: one layout at every width; the conversation is the base layer and the composer never leaves the bottom edge; a tap on a route slides the map and that route's data up over the transcript; Back returns to the conversation (the Google Maps model). The sub-decisions below are chosen here with the rejected alternative named; ratify or overturn them on U1's PR.

Shaped around what must not break: `MapView` is built once and destroyed on unmount, never resized (`MapView.tsx:72-87`); `ChatPanel` is hidden, never unmounted (`page.tsx:146-168`, `ChatPanel.tsx:403`), its emissions suppressed while hidden and replayed on unhide (`ChatPanel.tsx:127-134`, `:143-149`; pinned by `test/chat-panel-wiring.test.tsx:283-304`); ODbL on every view that draws data (`BRAND-SPEC.md:267-268`), today twice (`page.tsx:187-205`, `MapView.tsx:22-23,79`); the e2e clicks a transcript card, then its `.detail-toggle` (`e2e/smoke.spec.ts:112-139`), which a layer over the transcript intercepts.
